# Pixelskolan

Lågstadieskolan i [Snabbfilens](https://8bitcat.github.io/snabbfilen) pixelstad. Gör din figur, skriv in din klass, döp fröken och klasskompisarna, sätt dig i bänken och träna matte, klockan och svenska på tavlan. Efter fem uppgifter blir det rast.

Spela: **https://8bitcat.github.io/pixelskolan** (dator, iPad och iPhone)

- `index.html` – spelet
- `plan.html` – planen för hur skolan byggs in i Snabbfilen
- `skola.js` – skolan (klassrummet, närbilden på tavlan, uppgifterna, butiken, ditt rum)
- `sf/` – Snabbfilens egna filer: figurerna (`people.js`), figurskaparen (`avatar.js`), dialogerna (`ui.js`), typsnitten och möbelatlasen

Allt sparas i webbläsaren (localStorage).
